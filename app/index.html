EzMapMaker

Developed by John Edward L. Felipe, with AI-assisted implementation.

A modern desktop interface for the original MAPMAKER/EXP 3.0b.

How to use
  1. Prepare your folder. Put your .RAW file in a project folder. Use a short filename such as BSRR.RAW: up to eight characters before the extension, without spaces.
  2. Open the project. Click Open project folder and select that folder. MapMaker starts automatically.
  3. Enter commands. At the prompt, type prepare bsrr.raw (using your filename) and press Enter. Continue with your laboratory instructions. Type help for MapMaker command help.
  4. Find your results. Files written by MapMaker are saved in the same project folder. A .PS file appears after a drawing command creates it.
  5. Save and finish. Type quit, then press Enter or type y at the save prompt.

Scroll to review output; select text to copy. Use ↑ / ↓ for command history and Cmd/Ctrl + or − to adjust text size.

Add data files before opening a project. If you add a file later, quit and reopen the folder to import it.

How to cite EzMapMaker

Cite the original MAPMAKER software as well when reporting linkage analyses.
